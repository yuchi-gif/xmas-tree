# 电子圣诞树 · Merry Christmas

一个单文件、离线可运行的「电子圣诞树」动画。整棵树由发光粒子编织而成：八层锥形枝簇、粉白星尘、彩色灯珠、心形树顶、飘雪与地面星环，全部由 Canvas 实时绘制，没有任何外部图片、字体或模型请求。

树脚还会生成一组「幸运彩票码」（双色球 6 红 + 1 蓝），可以重编、复制，并把号码写进链接一起分享。

## 运行

直接双击 `index.html`，用任意现代浏览器打开即可（Chrome / Edge / Safari / Firefox）。

也可以起一个本地服务：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## Python 终端版

如果更喜欢原视频里的 Python 氛围，可以运行同目录的 `tree.py`（纯标准库，无需安装依赖）：

```bash
python tree.py
```

它会用 24 位真彩色和半格字符把终端当像素屏，画一棵会旋转、会飘雪的圣诞树。按 `Ctrl+C` 退出。
想直接打印一帧静态画面，用 `python tree.py --once`。

> 建议使用 Windows Terminal、iTerm2 或任意支持真彩色的现代终端；窗口越宽效果越细腻。

## 幸运彩票码

- 格式：双色球（6 个红球 01–33 + 1 个蓝球 01–16），每期号码随机生成，纯属娱乐。
- `再编一组`：重新生成一组号码，带逐颗弹出动画。
- `复制号码`：把期号、红蓝球和当前链接一起复制到剪贴板。
- 号码会写进地址栏的 `#lucky=...`，分享这条链接时，对方打开会看到**同一组号码**。
- 打开页面后默认自动生成一组并写入链接；刷新不会变，点“再编一组”才会换。

## 发布成链接

页面是单文件、零依赖，任意静态托管都能用。

1. **Netlify Drop（最快）**：打开 <https://app.netlify.com/drop>，把 `index.html` 拖进去，几秒后得到一个 `*.netlify.app` 链接。匿名站点 1 小时后过期且有临时密码，点结果页的 **Claim this site** 登录认领后即可永久保留并去掉密码。
2. **GitHub Pages**：把 `index.html` 推到仓库根目录，在 **Settings → Pages** 选择 `main` / `/ (root)`，访问 `https://<用户名>.github.io/<仓库名>/`。
3. **国内对象存储**：腾讯云 COS / 阿里云 OSS 开启静态网站托管，默认首页设为 `index.html`，对象设为公开读。

> 链接带 `#lucky=...` 时，请保证完整复制（包括 `#` 后面的部分），否则对方会看到新生成的一组号码。

## 实现要点

- **树形**：8 层锥形枝簇，每层按高度收窄半径，枝条上密布粉白粒子；层与层之间再用低亮度粒子填满，形成连续的锥体。
- **体积**：约 1 万个粒子：枝簇、针叶填充、树干、地面星场与同心星环，全部共用同一套 3D 投影。
- **投影**：手写 3D → 2D 透视投影（绕 Y 轴旋转 + 俯仰 + 焦距），粒子尺寸随景深缩放。
- **辉光**：粒子使用预渲染的径向渐变贴图，`lighter` 叠加；每帧再做一次 1/4 分辨率模糊回叠，得到柔和的泛光。
- **雪**：三层不同速度、大小、透明度的雪花，带正弦横向摆动，出屏后循环。
- **树顶**：心形轮廓 + 径向渐变填充 + 双层脉冲光晕，树长成后淡入。

## 可调参数

都在 `index.html` 的脚本顶部与 `buildScene()` 里：

- `TREE_HEIGHT / TREE_RADIUS`：树高与底半径
- `AUTO_SPIN`：自动旋转速度
- `starColor()`：粒子色板（默认粉白 + 少量玫瑰色）
- `buildScene()`：`TIERS` 层数、各层枝数、填充粒子数量
- `buildSnow()` 中的 `10500`：雪的密度（数值越小雪越多）
- `buildStars()` 中的 `4200`：星空密度

## 兼容性

需要支持 Canvas 2D、`filter` 与 `pointer` 事件的浏览器。页面无网络依赖，可直接拷走单独使用。
